Local dealer support / 01

Start with the operating requirement, not a catalogue number.

A diesel generator is part of a wider standby-power system. The useful first discussion is about what must remain operational, which loads start together, how long the DG may run, how the site changes over from utility supply and what installation work is already available.

Techno Electromechs brings the Mahindra Powerol product conversation together with load review, control planning and site coordination. Final model, configuration, duty and availability are confirmed during the project quotation rather than assumed from a broad capacity label.

Prepare the brief

Share the site application, running loads, motor details, starting method, essential-load priority, future expansion and target timeline. If some values are unknown, identify them as unknown so they can be reviewed.

DG selection / 02

Capacity is a result of the load study.

Connected load alone does not determine the correct DG. Motor starting current, starting method, load sequence, power factor, duty, environmental conditions and future expansion can all affect the recommendation. The generator sizing guide → explains how to prepare these inputs without presenting an online estimate as a final engineering decision.

INPUT 01

Running load

Identify the equipment that must operate during an outage and separate essential from optional loads.

INPUT 02

Motor starting

Record motor ratings, starting methods and whether large motors may start while other loads are connected.

INPUT 03

Operating duty

Describe expected outage duration, frequency, load variation and any critical operating constraints.

INPUT 04

Site conditions

Confirm access, environment, proposed DG position and the electrical interface with the facility.

Use the Mahindra Powerol DG range overview → to explore broad project bands before requesting a site-specific recommendation.

Project quotation / 03

Compare a complete project scope, not only the DG rating.

A quotation may need to account for the selected configuration, controls, AMF or changeover arrangement, delivery and unloading, foundation readiness, cabling, earthing, exhaust, ventilation, fuel arrangement, installation coordination, testing, commissioning and the agreed service scope. Items vary by project, so they should be written into the quotation rather than assumed.

The diesel generator quotation guide → sets out the information that helps make commercial comparisons clearer without publishing an unsupported fixed price.

Site integration / 04

Plan the room, electrical path and changeover before delivery.

Delivery access and equipment placement are only the beginning. A project review should consider the base or foundation, maintenance clearance, ventilation and hot-air discharge, exhaust routing, earthing, power and control cables, fuel provisions, fire and site requirements, and the commissioning sequence.

  • Installation planning: use the Kolhapur DG installation guide to review access, foundation, airflow, exhaust, cabling and earthing.
  • Automatic changeover: use the AMF panel guide to distinguish utility sensing, DG start command and the electrical transfer path.
  • Handover: agree the checks, operating demonstration, records and responsibilities needed before the system enters service.

Lifecycle planning / 05

Include readiness after commissioning.

A standby DG needs an operating and maintenance plan even when it runs infrequently. Equipment identity, running hours, alarms, inspections, consumables, defects and test observations should be recorded so future service decisions begin with evidence.

For an existing installation, share the make, model, rating, controller, age, running hours and available service history. The generator AMC and service guide → explains what can be considered when defining a preventive plan.

Kolhapur buyer questions / 06

Questions before requesting a DG quotation.

Where is Techno Electromechs based?

Techno Electromechs is based in Gokul Shirgaon, Kolhapur, and supports Mahindra Powerol DG requirements for commercial and industrial projects in the region.

Can I get a final kVA recommendation from connected load alone?

No. Running load, motor starting, load sequence, power factor, duty, future expansion and site conditions should be reviewed before final selection.

Do you publish a fixed diesel generator price?

No. The project quotation depends on the selected configuration and the required control, delivery, installation, commissioning and service scope.

Can installation and AMF requirements be discussed with the DG?

Yes. Share the existing electrical arrangement, essential load, proposed equipment location and project status so those interfaces can be considered together.
