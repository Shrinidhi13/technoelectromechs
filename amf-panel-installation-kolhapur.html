Automatic changeover AMF project guide

AMF panels for a controlled changeover.

Plan how the site detects a mains failure, starts the DG, transfers essential load and returns safely when utility supply stabilises.

Purpose / 01

Automation should follow the site’s operating logic.

An automatic mains-failure panel monitors the utility supply and coordinates DG starting and load transfer when approved conditions are met. When normal supply returns and remains stable, the sequence transfers the load back and allows the generator to complete its shutdown routine.

The concept is simple, but the correct panel and sequence depend on the electrical system, essential load, DG controls, switchgear and customer operating priorities. Techno Electromechs helps connect those inputs before panel integration.

Design principle

An AMF panel is not a universal box. Current rating, fault level, changeover arrangement, sensing, protection, interlocks, cable interfaces and control logic must match the approved site design.

Operating sequence / 02

What happens during a mains failure?

STATE 01

Monitor

The controller observes the utility supply against the configured operating conditions.

STATE 02

Start

After the approved delay and failure logic, the controller issues the DG start command.

STATE 03

Transfer

Once DG voltage and frequency are acceptable, the essential load transfers according to the design.

STATE 04

Restore

After stable mains return, the load transfers back and the DG completes cool-down and stop.

Actual timers, permissives, interlocks and alarm behaviour are set for the approved equipment and operating requirement. They should be documented and demonstrated during handover.

Required inputs / 03

Information needed before panel selection.

  • Supply arrangement: incoming source, voltage, phases, existing switchgear and protection.
  • Essential load: current, load type, priority, starting behaviour and any load-shedding plan.
  • DG controls: start interface, available signals, controller type and operating mode.
  • Changeover method: contactor, motorised switch or breaker-based arrangement as designed.
  • Safety interlocks: electrical and mechanical prevention of unintended source paralleling where not designed.
  • Indication and alarms: what operators need to see locally and what events must be recorded.
  • Manual operation: approved fallback and maintenance modes with clear operator instructions.

Integration / 04

AMF work crosses control and power circuits.

The installation should coordinate panel location, power-cable route, control wiring, sensing connections, earthing, clearances and access for safe inspection. Labelling and documentation help operators understand source status and help service teams diagnose issues later.

For new DG projects, AMF planning should occur alongside the installation and commissioning plan →, not after the generator is already in place.

Testing and handover / 05

Test the sequence—not only individual components.

  • Confirm sensing inputs, phase condition and configured voltage or frequency logic.
  • Verify start command, DG healthy feedback and failed-start or abnormal-state response.
  • Observe transfer and retransfer sequence using the approved test method.
  • Check interlocks, manual controls, indications, alarms and emergency stop interfaces.
  • Record settings, drawings, equipment details and operator instructions for handover.

AMF questions / 06

Common buyer questions.

Can an AMF panel be added to an existing DG set?

Often it can be evaluated, but compatibility depends on the existing DG controller, start interface, switchgear, electrical ratings and the condition of the current installation. A site review is required.

Does AMF mean the changeover is instant?

No. The sequence includes sensing, configured delays, engine starting, voltage and frequency stabilisation, transfer and later retransfer. Timing depends on the approved control philosophy.

Can some loads remain off during DG operation?

Yes, if the electrical design includes load prioritisation or shedding. The requirement should be defined during load assessment and panel planning.
